# Bases posters

Drop poster images (`.webp`, `.jpg`, `.png`, `.gif`) in this folder and they will be
auto-discovered by `src/lib/posterAssets.ts` (`CONVOCATORIA_POSTERS`).

Naming convention: prefix files with a numeric token to control display order
(e.g. `01-bases.webp`, `02-categorias.webp`). Files are sorted case-insensitively
with natural numeric ordering.
